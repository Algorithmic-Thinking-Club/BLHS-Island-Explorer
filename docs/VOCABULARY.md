# The words

Everything an island can ask the game to do. There are 36.

Put `yield` in front of one and it happens. Without the `yield` it builds a
dict, drops it, and the game never hears about it.

Every place is an anchor name somebody typed in MAPVIS, never an x and a y. A
name the map does not carry is refused on your own line.

Generated by `python tools/vocabulary.py`. Do not edit this file by hand.

## talking

| word | how you write it | what it does |
|---|---|---|
| `say` | `say(text, who=None, portrait=None)` | One line in the dialogue box. Comes back when the player clicks on. |
| `choose` | `choose(options, prompt=None)` | Buttons over the box. Comes back as the index the player picked. |

## showing him where to go

| word | how you write it | what it does |
|---|---|---|
| `guide_to` | `guide_to(anchor)` | Draw the arrow to an anchor. Comes back at once; he still walks himself. |
| `highlight` | `highlight(anchor, on=True)` | Light one thing up where it stands, with no arrow and no road to it. |
| `walk_to` | `walk_to(anchor, off=None)` | Take the controls and walk him there. Comes back when he arrives. |
| `look_at` | `look_at(anchor, ms=None)` | Point the camera at an anchor. `look_at(None)` gives it back to him. |

## his own body

| word | how you write it | what it does |
|---|---|---|
| `pose` | `pose(name=None, facing=None)` | Set what he is doing while standing still, and which way he is looking. |

## driving somebody else

| word | how you write it | what it does |
|---|---|---|
| `actor_move` | `actor_move(actor, to, off=None, facing=None, pace=None)` | Walk somebody to an anchor. Comes back when they get there. |
| `lead_to` | `lead_to(actor, to, off=None, pace=None)` | Somebody walks ahead to an anchor and the player follows them there. |
| `place` | `place(actor, at, off=None, facing=None)` | Put somebody at an anchor with no walk in it. For SETTING a scene. |

| `actor_look` | `actor_look(actor, look)` | Change which picture somebody is wearing, by the name MAPVIS gave it. |

## what you may pass

These are closed lists. Anything else is refused.

- `view(shot)`: `island`, `walk`, `close`, `ship`, `sail`
- `actor_move(pace=) and lead_to(pace=)`: `stroll`, `walk`, `run`
- `enter(cover=)`: `ceremony`, `passing`
- `open(ui)`: `planner`, `handbook`, `cords`, `chart`, `wardrobe`, `settings`, `wall`, `yearbook`, `tour`
- `get(path)`: `year`, `gpa`, `tokens`, `cords`, `flags`, `islands`, `handle`, `mode`, `graduated`, `cord_board`, `trophies`, `phase`, `picks`, `advisory`, `planned`, `rank`
