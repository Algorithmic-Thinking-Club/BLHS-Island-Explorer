### How I know nothing broke

Not by reading it. For all 21 files I parsed the before and the after, blanked
every docstring in both trees, and compared the dumps. Comments are invisible to
the parser, so a file that survives that comparison provably changed only its
comments.

**16 of 21 came out identical.** The other 5 differ by exactly the dead code I
removed on purpose, and nothing else:

- `islands/panther-maw/island.py`: two unused imports, `objective` and `turned`
- `tests/pump.py`: `answer.run = run`, and a `set_flag` branch reading a `name`
  key that nothing has ever sent
- `tests/test_the_club.py`: a `self.manifest` nothing read
- `tools/manifest.py`: a `claimed` set that was filled and never used
- `tools/sync.py`: `copy_folder` and `FROM_ENGINE_FOLDERS`

Each of those was put to three independent checks that tried to prove it was
still live before I touched it.
